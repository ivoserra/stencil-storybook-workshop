# Stencil + Storybook Workshop

A learning project following a Udemy workshop focused on building reusable Web Components with Stencil and documenting them with Storybook.

## Topics

- Stencil Web Components
- Storybook integration
- Component development and documentation
- Icon integration
- Tooltips and UI interactions
- React and Angular integration (future exploration)

## Purpose

Explore component architecture, reusable UI patterns, and cross-framework compatibility.
